# Zheng Shi — academic website deployment

**Live site:** https://zshigrit.github.io/EcoDynamics/

This repository publishes the personal website from [zshigrit/zshigrit.github.io](https://github.com/zshigrit/zshigrit.github.io). The published site uses its HTML, CSS, research images, and CV. The MyST files in this repository are no longer the source of the live website.

The original homepage was restored on September 25, 2026 from the [original homepage backup branch](https://github.com/zshigrit/zshigrit.github.io/tree/backup/original-homepage-2026-09-25). Source commit deployed: `854169d21d939a7b37b0d6d07f4fd326d304ced2`.

Edit the pages and assets in the [source repository](https://github.com/zshigrit/zshigrit.github.io/tree/main). To refresh the live `/EcoDynamics/` site after editing it, run the [deploy workflow](.github/workflows/deploy.yml) manually from the Actions tab, or push a change to this repository's `main` branch.
